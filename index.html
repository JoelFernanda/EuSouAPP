Como importar as planilhas

O sistema usa 2 planilhas diferentes. Cada uma tem uma função.

1. Cadastro de Ciclos (importa 1× por período)

Define qual SKU pertence a qual ciclo. Importe este arquivo uma vez no início do mês, antes de começar a contar.

CódigoDescriçãoCiclo
UN0001Camiseta P1
UN0002Camiseta M1
UN0010Calça Jeans2
UN0020Tênis Runner3
UN0030Boné Preto4

2. Estoque do Dia (importa toda vez que for contar)

Traz a quantidade em estoque (saldo) do dia. Importe antes de cada ciclo (16/09 para Ciclo 1, 18/09 para Ciclo 2, etc.).

CódigoDescriçãoCódigo de BarrasQuantidade
UN0001Camiseta P789115004987125
UN0002Camiseta M789609890225725
UN0010Calça Jeans789000011111140
Importante: importar uma nova planilha de Estoque do Dia em um ciclo não altera os ciclos anteriores. Cada ciclo congela o saldo no momento da importação.
